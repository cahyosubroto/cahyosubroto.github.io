                    Inline Catalog

                    Defines a catalog with schemas to enforce validation. The schemas are defined inline with the other properties.

                    catalog:
  type: inline
  options:
    subjects:
      items-snapshots:
        schema: |
          {
            "type": "object",
            "properties": {
              "id": {
                "type": "string"
              },
              "status": {
                "type": "string"
              }
            },
            "required": [
              "id",
              "status"
            ]
          }

                    Configuration (* required)

                    options

                    options

                    object

                    The inline specific options.

                    PropertyTypeDescription
                    options.subjectsobject as map of named object propertiesUnique identifier for schema categorization in the registry.
                    options.subjects.schema*stringDefinition specifying data structure and format in detail.
                    options.subjects.versionstringDefault: latest
